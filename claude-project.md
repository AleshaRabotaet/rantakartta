# Настройка проекта на claude.ai

1. Создайте проект «Rantakartta».
2. В базу знаний проекта загрузите: `docs/vision.md`, `docs/decisions.md`, `docs/sources.md`, `docs/schema.md`, `CLAUDE.md`.
   После каждого важного решения заменяйте `decisions.md` на свежую версию.
3. Инструкция проекта:

> Я делаю пет-проект Rantakartta: карту жилья у небольших хозяев Финляндии с фильтрами.
> Код пишу в Claude Code, здесь обсуждаю решения, источники данных и продукт.
> Отвечай по-русски и коротко. Учитывай, что делаю один и по вечерам: предлагай самое простое решение,
> которое работает. Сверяйся с файлами проекта; если твоё предложение противоречит decisions.md, скажи об этом.
> Когда решение принято, дай готовую строку для decisions.md.
> Когда задача готова для кода, сформулируй её как задание для Claude Code: цель, файлы, критерий готовности.

Цикл: обсудили в проекте → задание в Claude Code → код + тест → строка в decisions.md.
