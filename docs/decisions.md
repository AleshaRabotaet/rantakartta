# Журнал решений

Формат: дата, решение, почему. Новые сверху.

- **2026-09-25** Подложка OSM standard вместо CARTO: CARTO с августа 2026 требует ключ.
  При росте трафика перейти на MML или CARTO с ключом.
- **2026-09-25** Фронтенд без сборщика: один HTML + data.js. Причина: мало данных, быстро менять,
  хостинг на GitHub Pages. Пересмотреть при >5000 объектов.
- **2026-09-25** Парсер Johku разбирает страницу по текстовым меткам en_US, а не по CSS.
  Метки одинаковы на всех витринах движка.
- **2026-09-25** Три уровня точности координат: exact / merchant / area. На карте неточные
  точки с пунктирной рамкой. Объекты с одной точкой разводятся по спирали (`spread`).
- **2026-09-25** Из раздела жилья исключаем подарочные карты и многодневные каяк-туры.
- **2026-09-25** Источники: Johku-витрины сейчас; Visit Finland DataHub для покрытия страны позже;
  Johku API — после ответа Aptual Commerce (письмо Ilkka Lariola).
