# Роадмап

Задачи живут в GitHub Issues, сгруппированы по вехам (Milestones). Этот файл — только общая картина.
Создать бэклог: `bash scripts/create_backlog.sh` (нужен `gh auth login`).

## MVP — до 31.10.2026
Проверить, нужна ли карта кому-то кроме меня.
Данные настоящим парсером, 10–15 Johku-витрин, отчёт по точности координат, защита CI от поломки витрин,
фильтры в URL, «Сообщить об ошибке», аналитика без cookies, тест на 10 знакомых.

**Выход:** 500+ объектов, >50% с точностью exact, 3 из 10 знакомых вернулись сами.
Если никто не вернулся — остановиться и переосмыслить, а не строить дальше.

## v1.0 — до 01.02.2027
Первый релиз до сезона бронирования летних мёкки (январь–март).
Visit Finland DataHub + дедупликация, письмо в Johku с демо, RU/EN, страницы регионов для поиска,
приватность и удаление по запросу, свой домен, решение по подложке, план запуска.

**Цель:** 2000+ объектов по стране минимум из двух источников.
**Метрики первого месяца:** посетители, клики «Открыть у хозяина», доля вернувшихся.

## Потом
Доступность по датам (если Johku даст API) → эксперимент с монетизацией (виджет для региональных витрин
или реселлинг через Bókun) → подложка MML → зимние фильтры.

## Главные риски
- Качество координат — поэтому ручные overrides и отчёт по точности входят в MVP.
- Смена вёрстки Johku — защита в CI, в перспективе API.
- «Никому не нужно» — честный критерий выхода из MVP.
